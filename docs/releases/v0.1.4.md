# SSCapture v0.1.4

Windows 11 x64向け、未署名のプレリリースです。.NET 10 Desktop Runtimeを同梱します。

## 主な変更

- 入力・出力プリセットを各1件の既定設定として統合し、初期候補をそれぞれ3件用意しました。既定出力はクリップボードのみです。撮影中はプリセットから個別設定を今回だけ変更できます。
- 設定画面と右クリックメニューを整理し、つぶれたボタン、概要リンクでの未保存編集の消失、囲み直しへのスナップ精度の未反映を修正しました。吸着距離と刻み幅は別々に指定でき、初期値は20pxです。
- 画像の白い余白、256色/16色への減色、パレットPNG/DIBのクリップボード出力、固定サイズや前回範囲の再撮影に対応しました。
- 通知クリックの動作と登録アプリの選択、ポインタ接近中の表示時間保持、暗転設定、撮影情報のPNG内XMP/別JSON記録を追加しました。
- ペイントを初回だけ外部アプリへ登録します。既存の登録と選択を保持し、外部アプリ画面と既定出力プリセットの選択を同期します。外部出力を勝手にONにはせず、削除したペイントを再登録しません。
- KotorinToysでの検出に必要な製品定義・管理補助・配布所有物目録を同梱し、旧v0.1.2からの更新と失敗時の復旧を改善しました。設定・撮影ファイル・利用者が配置したFFmpeg等は配布所有物として削除しません。

## 配布と注意

公開候補はRelease警告0/エラー0、通常回帰532件、管理補助23件、配布検査46件、ビルド手順7件が成功しました。専用環境で新規導入、同一PIDでの起動/設定表示/状態取得、通常終了、旧版更新、配置後故障の復旧、更新/削除時の利用者ファイル保持も確認しています。元の導入・登録・予約は復元済みです。

配布物はsetup EXE、`SSCapture-packages.json`、`SSCapture-SHA256SUMS.txt`の3点です。目録の`unsigned-public-build`はデジタル署名済みという意味ではありません。FFmpeg/FFprobeとOneOCRは同梱していません。録画/OCRには別途対応環境が必要です。

旧setupでKotorinToysから「確認できない」と表示される場合は、[復旧手順](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.4/docs/recovery.md)を参照してください。更新時は録画・出力を完了してください。強制終了や個人設定の削除は行いません。

フォト・Clipchampへの実ファイル連携は未確認です。別PC・実複数モニター/混在DPI、物理音声等の確認範囲は[検証状況](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.4/dev/validation.md)と[版別報告](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.4/dev/history/v0.1.4/v0.1.4-imp.md)を参照してください。未確認項目を確認済みとして公開しません。
