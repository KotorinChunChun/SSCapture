# SSCapture v0.1.8

Windows 11 x64向けの未署名プレリリースです。.NET Desktop Runtimeを同梱しています。

- 出力プリセットに「ピン留め表示」を追加しました。撮影した静止画を撮影位置に枠なし・最前面で残し、複数枚を並べて移動できます。
- ピン留め画像へ赤3pxのペン、水平・垂直線、図形・文字・蛍光ペンで注釈を付けられます。Undo/Redo、範囲コピー、指定フォルダーへの保存、拡大縮小、L/Rでの90度回転にも対応します。
- 設定の「撮影コマンド」で、実行時に範囲を選ぶ方式と固定座標を撮る方式のPowerShellコマンドを生成できるようにしました。入力・出力プリセットを指定でき、生成だけでは撮影しません。
- 正式導入版で自動起動の設定を利用できないと表示される問題を修正しました。既存の起動予約は保持します。

ピン留めは静止画専用で、窓と注釈はアプリ起動中だけ保持します。必要な画像は閉じる前にコピーまたは保存してください。

FFmpeg/FFprobeとOneOCRの外部ファイルは同梱しません。録画には別途FFmpegが必要です。混在DPIなど全環境の動作を確認したものではありません。[操作方法](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.8/docs/usage.md)・[検証範囲](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.8/dev/validation.md)を参照してください。
