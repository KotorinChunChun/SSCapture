# SSCapture v0.1.11 (beta)

- 矩形をドラッグまたは2回のクリックで選択できます。拡大鏡と矢印キーで画素単位の位置を確認できます。拡大鏡は撮影に含む画素の境界を赤線で示し、ドット数と倍率を設定できます。
- 撮影中の修飾キーに部品選択を割り当てると、ボタンや入力欄を選んで撮影できます。ドラッグで複数のコントロールを1枚に合成できます。選んだウィンドウの画像は、出力プリセットで四辺を指定して切り抜けます。
- 単一のウィンドウ・コントロール、矩形のドラッグ、固定サイズの枠を、ホイール1目盛りごとに四辺1物理pxずつ広げ・狭められます。Spaceで基点を切り替えても調整量を保ちます。
- スクロール撮影を追加しました。選んだ領域を縦にスクロールし、重なりを照合して1枚の縦長の静止画にします。
- 「撮影操作を画面共有・配信に表示する」で、モニター全体の配信に選択枠や操作ガイドを表示できます。初期設定はOFFです。
- 入力・出力プリセットの組に、静止画・録画のキーを登録できます。時限撮影と定期撮影は設定画面とCLIから開始できます。
- 「直前の設定で再撮影」で、起動中に最後に成功した静止画の対象を、確定時の入出力条件で撮り直せます。キー設定とトレイの「前回の範囲」は廃止しました。
- 静止画の撮影開始タイマーを追加しました。入力プリセットと撮影中の右クリックから、待ち時間なし・3秒・5秒・10秒を選べます。
- 1点目と2点目の中クリックの既定を拡大鏡の表示切替にしました。コントロール選択とウィンドウ撮影のプッシュ・トグルは1点目の修飾キーごとに選べます。
- 設定に「バージョン情報」を追加しました。バージョン・更新日・作者・概要を確認し、「使い方」「アップデート情報」「不具合を報告」からGitHubを開けます。
- 白い余白は出力プリセットで指定するようになりました。以前の入力プリセットの値は引き継ぎます。
- 新規設定の標準固定サイズを960×540・800×600・320×240pxにしました。Win＋Shift＋Qで960×540pxの枠から撮影を始めます。編集済みの固定サイズは変更しません。
- 設定の書き出し・取り込みと、各設定ページの「初期設定に戻す」に対応しました。自動起動は基本設定の専用ボタンで適用できます。
- 通知の表示先の初期値をメイン画面の右下にしました。画面右下の操作ガイドは、メイン画面と撮影モニターのどちらに出すかを選べます。
- Snipping Toolを外部編集アプリに登録できます。未保存画像を渡すときも出力プリセットの命名パターンを使います。
