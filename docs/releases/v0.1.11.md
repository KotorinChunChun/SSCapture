# SSCapture v0.1.11

- 矩形をドラッグまたは2回のクリックで選択できます。拡大鏡と矢印キーで画素単位の位置を確認できます。
- 撮影中の修飾キーに部品選択を割り当てると、ボタンや入力欄を選んで撮影できます。選んだウィンドウの画像は、出力プリセットで四辺を指定して切り抜けます。
- 「撮影操作を画面共有・配信に表示する」で、モニター全体の配信に選択枠や操作ガイドを表示できます。初期設定はOFFです。
- 入力・出力プリセットの組に静止画用のキーを登録できます。時限撮影と定期撮影は設定画面とCLIから開始できます。
- 設定の書き出し・取り込みに対応しました。自動起動は基本設定の専用ボタンで適用できます。
- Snipping ToolとScreenpressoを外部編集アプリに登録できます。未保存画像を渡すときも出力プリセットの命名パターンを使います。
