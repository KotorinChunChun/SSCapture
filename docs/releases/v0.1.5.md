# SSCapture v0.1.5（公開候補・未公開）

Windows 11 x64向け、未署名プレリリースの候補です。最終UI受入・導入検査・GitHub公開はまだ完了していません。

## 主な変更

- px吸着は新規OFF、吸着距離と刻み幅は別々に20px。矩形のモニタ端・角を刻み丸めより優先し、負座標を回帰検査しました。
- 撮影メニューのルートに入力/出力プリセットを配置。「一時入力カスタマイズ」「一時出力カスタマイズ」に整理し、数値・文字列フォームは設定画面へ集約。末端コマンドを選んだら全階層を閉じます。
- 入力は「囲った範囲」と720p/1080p/1440p/4Kの固定サイズを初期登録。「固定位置とサイズ」、プリセットごとの録画・音声にも対応。出力の既定名は「クリップボード」です。
- 入出力プリセットは「追加▼」「削除」「既定にする」の3ボタンと自動保存へ統一。不完全な入力は確定せず、基本・通知など他カテゴリは従来の手動保存を維持します。
- 「直前と同じ設定で再撮影」を追加。成功した静止画の範囲と一時変更込みの設定で新しく取得し、OCR・日時・連番も更新します。キーは初期未割当、画像履歴とは別に起動中だけ保持します。
- 通知は8方位＋中央。「フォルダを開く」「外部アプリで編集」と再撮影キーを表示。本文はクリック透過、ボタンだけ入力を受けます。未保存画像は編集操作時だけ一時PNGを生成します。
- Windows自動起動は初期OFF。通常起動は設定画面、`--startup`/`--hidden`は無表示。KotorinToysと同じユーザー別予約を使い、ビルドや起動だけでは登録しません。

既存の利用者設定・編集済みプリセット・キー・スナップON/OFFは保持します。確実に未編集の初期候補のみ移行します。削除した候補は繰り返し復活させません。

Release警告0/エラー0、通常回帰559件・管理補助24件・ビルドscript7件・配布fixture46件成功。切断中のWindowsでは実入力を確認できず、メニュー→ドラッグ復帰・別プロセス上の通知操作は未確認です。確認するまで公開しません。
