# SSCapture v0.1.5

Windows 11 x64向けの未署名プレリリースです。確認済みの実操作と、未確認の条件を区別して公開します。

## 主な変更

- px吸着は新規OFF、吸着距離と刻み幅は別々に20px。矩形のモニタ端・角を刻み丸めより優先し、負座標を回帰検査しました。
- 撮影メニューのルートに入力/出力プリセットを配置。「一時入力カスタマイズ」「一時出力カスタマイズ」に整理し、数値・文字列フォームは設定画面へ集約。末端コマンドを選んだら全階層を閉じます。
- 入力は「囲った範囲」と720p/1080p/1440p/4Kの固定サイズを初期登録。「固定位置とサイズ」、プリセットごとの録画・音声にも対応。出力の既定名は「クリップボード」です。
- 入出力プリセットは「追加▼」「削除」「既定にする」の3ボタンと自動保存へ統一。不完全な入力は確定せず、基本・通知など他カテゴリは従来の手動保存を維持します。
- 「直前と同じ設定で再撮影」を追加。成功した静止画の範囲と一時変更込みの設定で新しく取得し、OCR・日時・連番も更新します。キーは初期未割当、画像履歴とは別に起動中だけ保持します。
- 通知は8方位＋中央。「フォルダを開く」「外部アプリで編集」と再撮影キーを表示。本文はクリック透過、ボタンだけ入力を受けます。未保存画像は編集操作時だけ一時PNGを生成します。
- Windows自動起動は初期OFF。通常起動は設定画面、`--startup`/`--hidden`は無表示。KotorinToysと同じユーザー別予約を使い、ビルドや起動だけでは登録しません。
- 動作と画面配置を保ち、再撮影設定・プリセット自動保存・通知判断を責務別に整理しました。

既存の利用者設定・編集済みプリセット・キー・スナップON/OFFは保持します。確実に未編集の初期候補のみ移行します。削除した候補は繰り返し復活させません。

## 検証・配布

Release警告0/エラー0、通常回帰574件・管理補助24件・ビルドscript7件・配布fixture46件成功。設定画面の配置とプリセットの自動保存、利用者の直接操作による矩形メニュー選択直後のドラッグ、通知の編集ボタンと通知再作成後のフォルダーボタンを確認しました。通知ボタンは各1回だけ処理され、背後へのクリック漏れがなく、元のウィンドウの前面を維持しました。通常起動したv0.1.5の設定画面表示と応答も確認しています。

配布はsetup EXE、`SSCapture-packages.json`、`SSCapture-SHA256SUMS.txt`の3点。.NET 10 Desktop Runtime同梱、FFmpeg/FFprobe・OneOCR・個人設定は非同梱です。最新ソースから新規発行し、setupの非実行展開で両配置の全ファイル・目録・SHA256を照合し、秘密情報検査を行います。署名済みインストーラーではありません。

内部整理前の候補では、専用配置での新規導入/旧版更新/故障復旧/削除を確認し、元の通常導入環境へ復元しました。今回の公開用再生成ではsetupを実行せず、展開と内容照合を行います。旧候補の導入試験を、今回のsetupで実行した試験とは扱いません。

## 未確認の範囲

- メニューの実入力確認は矩形への切替後の最初のドラッグです。全末端コマンド・変更失敗・画面再取得失敗後の全経路は自動回帰の対象であり、実入力では網羅していません。
- 通知は未保存画像の編集と、ハンドル再作成後の保存済み画像のフォルダー操作を確認しました。Explorer/外部アプリは検証用の代替処理のため、実アプリ起動後の前面制御、全表示位置/DPIの組合せは未確認です。
- 実サインインによる自動起動、別PCでの実複数モニタ・混在DPI、物理音声等は未確認です。

これらを実測完了とせず、制限を明示したプレリリースとして提供します。詳細は[検証状況](../../dev/validation.md)と[版別報告](../../dev/history/v0.1.5/v0.1.5-imp.md)を参照してください。
