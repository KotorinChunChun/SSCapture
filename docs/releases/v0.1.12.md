# SSCapture v0.1.12 (beta)

撮影範囲の文字や表を直接コピーできるようになりました。撮影履歴は、保持日数と再起動後の復元を設定できます。

[SSCaptureの概要・使い方（README）](https://github.com/KotorinChunChun/SSCapture#readme)

## ダウンロード

Windows 11 x64向けです。.NET 10 Desktop Runtimeを同梱しています。OCRにはOneOCR、録画にはFFmpegとFFprobeが必要です。これらの外部ツールは別途用意してください。

- `SSCapture-0.1.12-setup.exe` はインストーラーです。
- `SSCapture-SHA256SUMS.txt` でダウンロードしたファイルのSHA-256を照合できます。
- `SSCapture-packages.json` はKotorinToys用の配布台帳です。

インストーラーは未署名のベータ版です。[Microsoft Edgeでのダウンロード手順](https://github.com/KotorinChunChun/KotorinToys/blob/main/docs/github-release-download-edge.md)

## インストール・更新

- 新規導入は `SSCapture-0.1.12-setup.exe` を実行してください。
- 更新時はトレイからSSCaptureを終了し、既存の導入先にインストールしてください。設定や保存済みの撮影ファイルは引き継ぎます。
- KotorinToysから導入した場合は、ツール一覧のSSCaptureからインストール・更新できます。

## 確認範囲・制限

- Windows 11で管理者権限での手動再起動、OneOCRでの文字・表認識、コントロール撮影を確認しました。
- 管理者対応のサインイン自動起動用補助は今回の配布に含まれません。

## 主な変更

- Win＋Shift＋Tで文字、Win＋Shift＋Lで表を撮影できます。静止画の出力プリセットでは画像・テキスト・表（TSV）・ファイルパスを選べます。
- OneOCRで小さい日本語の再認識、本文の折り返しや表の狭い列の判定を改善しました。
- ウィンドウを左ボタンで押している間も、ホイールで撮影範囲を物理ピクセル単位で調整できます。基準枠と調整後の撮影枠を確認できます。
- ウィンドウの描画領域だけを撮影できます。コマンドラインからもハンドルや実行ファイル名でウィンドウを指定できます。
- Ctrl＋ドラッグで複数のコントロールを選ぶと、間の背景を含む外接矩形をプレビューして撮影できます。
- 通知から保存済みファイルのパスをコピーできます。履歴から画像をドラッグで渡したり、複数選択して削除したりできます。履歴のディスク保存は初期設定でOFFです。
- 拡大鏡の初期値は20×20ドット・4倍です。「直前の設定で再撮影」の初期キーはWin＋Ctrl＋Alt＋Sです。保存済みの設定とキー割り当てを引き継ぎます。
- 「基本」の「管理者として実行」を適用すると、「再起動」から管理者権限へ切り替えられます。初期設定はOFFです。
