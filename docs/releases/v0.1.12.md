# SSCapture v0.1.12 (beta)

- 新規設定と即時撮影キーの初期化で、Win＋Ctrl＋Alt＋Sを「直前の設定で再撮影」に割り当てます。既存の割り当てを引き継ぎます。

- ウィンドウを左ボタンで押している間も、ホイールで撮影範囲を物理ピクセル単位で調整できます。基準枠と調整後の撮影枠を確認できます。
- ウィンドウの描画領域だけを撮影できます。コマンドラインからもハンドルや実行ファイル名でウィンドウを指定できます。
- 通知から保存済みファイルのパスをコピーできます。履歴はプレビューをドラッグして渡せるほか、複数選択で整理できます。
- 静止画の通知と履歴から、OneOCRで文字や表をクリップボードにコピーできます。
- 「基本」に、管理者権限のアプリで撮影ショートカットを使うための「管理者として実行」を追加しました。初期設定はOFFです。適用後は「再起動」から権限を切り替えられます。
