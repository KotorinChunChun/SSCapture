# SSCapture v0.1.6

Windows 11 x64向けの未署名プレリリースです。.NET Desktop Runtimeを同梱しています。

## 更新内容

- 0.1.1から更新すると、旧インストーラーの日本語の製品登録名や0.1.0の製品定義が残っている場合に停止する問題を修正しました。
- 旧版の正式登録と公開配布ファイルを照合したうえで更新します。設定・履歴・撮影結果と利用者が配置したFFmpegは保持します。配布ファイルが変更されている場合は上書きせず中止します。
- 未署名のため、Windowsが警告を表示する場合があります。SHA256SUMSでダウンロードしたファイルの一致を確認できます。

FFmpeg/FFprobeとOneOCRの外部ファイルは同梱しません。録画には別途FFmpegが必要です。複数画面・混在DPI・物理音声など、すべての環境の動作を確認したものではありません。確認結果は[検証状況](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.6/dev/validation.md)を参照してください。
