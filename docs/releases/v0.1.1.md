# SSCapture v0.1.1

Windows 11 x64向けの未署名開発版です。.NET 10 Desktop Runtimeを同梱します。

## v0.1.0公開版からの変更

- 解像度や配置の異なる複数画面で選択画面が別のモニタへ移動する問題を修正しました。FancyZonesの自動配置にも対応します。
- 撮影開始時にポインタがあった画面だけを暗転し、選択・ポインタをその画面に限定する設定を追加しました。既定はONです。OFFのときは複数画面にまたがる範囲も選べます。
- 矩形ドラッグ中、Shiftで高さ、Ctrlで幅を固定できます。Altを押している間は20px単位とデスクトップ枠への吸着が働きます。
- ドラッグ中の右クリック・Escapeで選択だけを中断し、撮影モードを維持できます。
- 撮影中の右メニューへ「デスクトップ全体 (中央クリック)」、20px単位の切替、一時撮影モードを追加しました。
- 左クリックだけのウィンドウ選択で透過画面が判定を妨げる問題と、一時モードのメニュー残留・フォーカスの問題を修正しました。
- 「撮影タイミング」の設定説明と各設定のツールチップを整備しました。撮影開始時の画面固定がOFFのときは、選択画面を閉じた後に取得します。
- 完了通知へ対象デスクトップと座標を表示します。例: `デスクトップ【1】全体をコピーしました`、`デスクトップ【1】の 【100,100】 ～ 【200,200】 をコピーしました`。
- 従来の`System32/mspaint.exe`設定でペイントを起動できない環境では、Windowsの実行エイリアスへ解決します。保存ON/OFFの両方に対応します。
- 描画、通知書式、ペイントの実行ファイル判定を整理し、配布物の再生成と検査手順を追加しました。

## 更新と依存物

起動中のSSCaptureをトレイから終了し、インストーラーを実行してください。導入先とAppIdは従来どおりです。`data`内の設定・履歴・作業データ、保存した撮影結果、利用者が別途配置した`tools`は更新・削除時に保持します。

FFmpeg/FFprobeとOneOCRの外部ファイルは同梱しません。録画を使う場合は[FFmpeg公式の案内](https://ffmpeg.org/download.html)から信頼できる配布元を選び、`ffmpeg.exe`と`ffprobe.exe`を導入先の`tools`へ配置してください。静止画撮影はこれらがなくても利用できます。OCRは本機の対応するSnipping Toolに依存します。

## 確認範囲

Releaseビルド警告0・エラー0、通常回帰353件成功。配布物の版・ランタイム・除外ファイル・SHA256を検査しています。実機測定と未確認範囲は[検証状況](../../dev/validation.md)を参照してください。混在DPIや全撮影・実録音経路の受入完了を示すものではありません。
