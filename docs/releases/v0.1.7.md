# SSCapture v0.1.7

Windows 11 x64向けの未署名プレリリースです。.NET Desktop Runtimeを同梱しています。

- 登録0.1.0・実行ファイル0.1.1という既知の旧版の組合せから更新できるようにしました。
- 正式な登録先と旧版の配布物を照合し、設定・履歴・撮影結果と利用者が配置したFFmpegを保持します。照合できないファイルは上書きしません。
- 0.1.1として正しく登録された旧版からの更新にも引き続き対応します。

FFmpeg/FFprobeとOneOCRの外部ファイルは同梱しません。録画には別途FFmpegが必要です。混在DPI・物理音声など、すべての環境での動作を確認したものではありません。確認結果は[検証状況](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.7/dev/validation.md)を参照してください。
