# SSCapture v0.1.10

Windows 11 x64向けの未署名プレリリースです。.NET 10 Desktop Runtimeを同梱します。

- Winの短押しでウィンドウ撮影へ切り替えます。Windows Graphics Captureによる対象ウィンドウのプレビューと撮影、左ドラッグによる複数ウィンドウの合成に対応しました。中ボタンドラッグでは通過した複数のモニターを合成できます。
- 撮影範囲の設定前とドラッグ中の操作を分けて設定できます。既定ではドラッグ中のShiftで縦横比を固定、Ctrlで中心から広げ、Winで別モニターへの移動を許可、Win＋Altでグリッドを一時的に有効にします。固定サイズの基点は四隅と中心から選べます。
- 直前に撮影したウィンドウやモニターは現在の位置で再撮影できます。対象を識別できない場合は選び直しを案内します。対象の追跡はアプリの起動中に有効です。
- 操作ガイドは画面右下とポインタ横を個別に切り替えられます。通知には対象のウィンドウ名、または左上座標と幅・高さを表示し、サムネイルのダブルクリックで割り当て済みの編集アプリを開けます。
- 録画に必要なファイルが不足している場合は、範囲を選ぶ前にファイル名と配置先を案内します。インストーラーに操作画像とSSCaptureのライセンスを同梱しました。

録画にはFFmpeg・FFprobeの別途配置が必要です。Excelへの画像ドロップは外部受け取りに対応したOfficeAssistで利用できます。すべての混在DPI構成や外部アプリでの動作を確認したものではありません。[使い方](../usage.md)
