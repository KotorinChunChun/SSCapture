# SSCapture v0.1.9

Windows 11 x64向けの未署名プレリリースです。.NET Desktop Runtimeを同梱しています。

- 撮影通知を白基調の角丸カードへ変更しました。小さな撮影画像、フォルダ・編集ボタン、再撮影ショートカットを表示します。
- 通知の小画像をフォルダへドラッグすると保存済みの元画像を移動します。Ctrlを押しながらドロップすると元画像を残してコピーします。
- 画像ファイルのドロップに対応するアプリへ画像を渡せます。アプリへ渡す場合は元画像を残します。未保存画像はドラッグを開始したときに一時PNGを生成します。
- ドラッグ中は通知を消さず、キャンセル時は表示時間を戻します。

KotorinToysのツール一覧からインストール・更新できます。Excelへドロップするには、外部アプリからの画像受信に対応したOfficeAssistが必要です。PowerPointは利用者による挿入成功、修正版OfficeAssist経由のExcelは利用者操作とこちらでのGUI表示・キャンセル確認を行いました。すべてのアプリが画像ドロップに対応するわけではありません。

FFmpeg/FFprobeとOneOCRの外部ファイル、個人設定・撮影画像は同梱しません。録画には別途FFmpegが必要です。実機の複数モニタ・混在DPIなど、すべての条件を確認したものではありません。[操作方法](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.9/docs/usage.md)・[検証範囲](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.9/dev/validation.md)を参照してください。
