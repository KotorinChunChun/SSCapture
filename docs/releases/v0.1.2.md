# SSCapture v0.1.2

Windows 11 x64向けの未署名開発版です。.NET 10 Desktop Runtimeを同梱します。

## v0.1.1公開版からの変更

- 矩形ドラッグ中のSpaceで、現在のポインタ位置を新しい始点にして囲み直せます。固定サイズではSpaceのたびに基点を左上→右上→右下→左下の時計回りに切り替えます。
- 撮影中の右クリックから、矩形の縦横比を自由・16:9・4:3・1:1に切り替えられます。
- Shift/Ctrlによる方向ロックを解除すると、選択端が現在のポインタ位置に戻ります。
- 「撮影範囲の選択」ガイドを×で閉じても撮影状態を維持します。表示設定を保存し、右クリックから再表示できます。ドラッグ中のポインタが近づいた際は一時的に隠れます。
- 基本設定の「画像の余白 (px)」で、撮影範囲の外側へ上下左右同じ幅の白い余白を追加できます。元画像は縮小しません。今回だけの余白は撮影中の右クリックで変更できます。
- 撮影プリセットで出力方法・余白・保存先・命名の組合せを保存し、撮影中に呼び出せます。既定設定を変えず今回の撮影だけに適用できます。
- トレイの「失敗した出力を再実行」で、直近の静止画の失敗した処理だけをやり直せます。成功済みの出力を重複実行しません。次の静止画出力や終了で保持を解放し、保持上限は256MiBです。録画・再起動後の復旧は対象外です。
- README序盤にWindows標準の撮影との違い、適した用途、CapchunWindowとの使い分けを整理しました。

## 更新と依存物

起動中のSSCaptureをトレイから終了し、インストーラーを実行してください。AppIdと既定導入先は従来どおりです。利用者の`data`・保存画像・別途配置した`tools`は更新・削除時にも保持します。

FFmpeg/FFprobeとOneOCRの外部ファイルは同梱しません。録画には[FFmpeg公式の取得案内](https://ffmpeg.org/download.html)に従って信頼できる配布元から取得した`ffmpeg.exe`と`ffprobe.exe`を導入先の`tools`へ配置してください。静止画撮影はこれらがなくても利用できます。
