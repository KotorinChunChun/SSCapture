# SSCapture v0.1.13 (beta)

2026年11月27日の最終差し替え版では、Winで選んだウィンドウの隠れた部分もWGCで撮影できます。Edgeの短い文字ラベルのCtrl撮影を修正し、通常の左単押しで撮る対象を設定できるようにしました。

Excelを撮影して「表をコピー」すると、グリッド線から列の位置を読み取ります。1行だけの表や途中に空欄がある表も、列の並びを保って貼り付けられます。

[SSCaptureの概要・使い方（README）](https://github.com/KotorinChunChun/SSCapture/blob/v0.1.13/README.md)

## ダウンロード

Windows 11 x64向けです。.NET 10 Desktop Runtimeを同梱しています。OCRにはOneOCR、録画にはFFmpegとFFprobeが必要です。これらの外部ツールは別途用意してください。

- `SSCapture-0.1.13-setup.exe` はインストーラーです。
- `SSCapture-SHA256SUMS.txt` でダウンロードしたファイルのSHA-256を照合できます。
- `SSCapture-packages.json` はKotorinToys用の配布台帳です。

インストーラーは未署名です。[Microsoft Edgeでのダウンロード手順](https://github.com/KotorinChunChun/KotorinToys/blob/main/docs/github-release-download-edge.md)

## インストール・更新

- 新規導入は `SSCapture-0.1.13-setup.exe` を実行してください。
- 更新時はトレイからSSCaptureを終了し、既存の導入先にインストールしてください。保存済みの設定と撮影ファイルは引き継ぎます。メモリのみに保持する履歴は終了時に消えます。
- KotorinToysから導入した場合は、ツール一覧のSSCaptureから更新できます。

## 確認範囲・制限

- Windows 11で、Excelの表のOCRと、モニター境界に近い位置での通知領域サブメニューの表示を確認しました。
- 管理者権限が必要なアプリ向けの、サインイン自動起動用補助は今回の配布の対象外です。

## 主な変更

- 選択画面と拡大鏡で、実際に撮影する範囲の境界を赤線に統一しました。矩形選択では、ポインタを通る全画面ガイド線を使えます。画面右下の操作ガイドは、最初のクリック前でもポインタが近づくと退避します。
- 画面固定中にCtrlで選んだコントロールは、開始時の画素を使います。位置を確認できない場合は、同じ固定画面で範囲選択を続けられます。
- 遅延撮影に残り秒数とバーを表示します。待機中はEscで取り消せます。定期撮影は、標準の「ファイル保存」を復元した後も、その保存先と命名設定を使います。
- 撮影中のメニューから設定を開けます。通知領域のメニューを操作ごとに整理し、対応するショートカットを表示します。サブメニューは親と同じモニターに表示します。
- 画像・動画それぞれの既定の編集アプリを、一覧の★で確認できます。「既定にする」で即時保存します。通知の設定では画像用と動画用の同名アプリを見分けられます。
- 履歴から画像を再コピー・編集した後も、「前回の撮影結果」には直近に撮影した画像を表示します。「直前の設定で再撮影」の初期キーはWin＋Ctrl＋Shift＋Sです。保存済みのキー割り当てを引き継ぎます。
- 出力プリセットと「静止画のコピー内容」の名称を「OCR（文字列）」「OCR（表）」に統一しました。

## 2026年11月27日 最終差し替え

- Winでのウィンドウ撮影は画面固定にかかわらずWGCを使います。ウィンドウの見えている部分を指せば、隠れている部分も撮影できます。カーソルを含める場合は、開始時に対象内にあったカーソルをその位置と形で重ねます。
- Edgeで、画面固定中にページ左上の短い文字ラベルをCtrl＋左クリックで選べない場合がある問題を修正しました。実際のEdgeで、開始後にラベルの表示色を変え、開始時の画像がクリップボードに入ることを確認しました。
- 「ショートカット」→「1点目」→「左単押し」で、修飾キーなしの撮影対象をウィンドウ・モニター・コントロール・なしから選べます。既定はウィンドウです。

重なった実ウィンドウで、背面の画素がWGCプレビューと確定画像に入ることを確認しました。混在DPIでの実操作は未確認です。

先にv0.1.13を導入済みの場合は、SSCaptureを終了し、このページからセットアップを取得し直して同じ導入先にインストールしてください。差し替え後のセットアップに対応するSHA-256は、同じページの一覧で確認できます。

## 2026年11月25日 差し替えの記録

この時点の配布では、画面固定中にCtrlやWinで選んだ対象に開始時の画面を使うようにしました。Chromeでは撮影開始後にボタンの色を変え、開始時の画素がクリップボードに入ることを確認しました。WinFormsでもCtrlとWinによる撮影を確認しました。Win撮影の方式は11月27日の最終差し替えでWGCへ更新しました。
