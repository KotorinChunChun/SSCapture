# SSCapture v0.1.13（開発中）

「表をコピー」でExcelのグリッド線からセルの位置を読み取るようにしました。1行だけの表や、文字の列と数値の列の間に空欄がある表も、列の並びを保ってTSVとしてコピーできます。[表コピーの使い方](../usage.md#撮影画像の文字表をコピーする)

- 画面右下の操作ガイドは最初のクリック前にも退避します。拡大鏡にポインタの青十字と撮影境界の赤線を表示し、ホイールで変更した実際の量を操作ガイドで確認できます。[画素単位の選択](../usage.md#画素単位で範囲やコントロールを選ぶ)
- 画面固定中はWinやCtrlで撮影方式を切り替えても、開始時の画素と写し込むポインタを使います。開始時の映像から対象を確認できない場合は、理由を表示します。[画面固定とカーソル](../usage.md#画面固定とカーソル)
- 遅延撮影に残り秒数とバーの表示を追加しました。待機中はEscで取り消せます。[撮影開始タイマー](../usage.md#撮影開始タイマー)
- 撮影中の右クリックから「設定」を直接開けるようにしました。通知領域のメニューは操作ごとに区切り、同じ操作を行うショートカットを項目の右側に表示します。[メニューの使い方](../usage.md#撮影中の右クリックメニュー)
- 画像用・動画用の既定の編集アプリを、外部アプリの一覧で★を付けて指定できます。通知設定では、同名の登録を用途で見分けられます。[外部アプリの設定](../settings.md#外部アプリ)
- 履歴の再コピーや編集の後も「前回の撮影結果」は直前に撮った画像を表示します。定期撮影は、標準の「ファイル保存」を復元した後も、その保存先と命名設定を使います。[撮影履歴](../usage.md#同じ範囲固定サイズ撮影履歴)・[タイマー撮影](../usage.md#タイマー撮影)
