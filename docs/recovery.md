# KotorinToysでSSCaptureを認識できない場合

v0.1.2の公開setupには、KotorinToysが製品を識別するための`tool.json`が不足しています。
ダウンロードやsetupが成功しても、本体では「確認できない」となり、起動・更新ボタンが無効になる場合があります。

## 修正版での復旧

v0.1.3は現在ローカル検証中で、まだ公開していません。以下は修正版公開後の手順です。

1. [SSCaptureの正規Release](https://github.com/KotorinChunChun/SSCapture/releases)から修正版setupを取得します。旧v0.1.2を繰り返し実行してもこの不足は直りません。
2. 撮影・録画・出力を完了し、修正版setupを実行します。本体で無効になった更新ボタンを使う必要はありません。
3. 既存の導入先へ更新します。日本語・空白を含む独自の導入先も維持します。製品・登録先を照合できない場合は中止し、別のフォルダーへ無理に上書きしないでください。
4. KotorinToysで状態を再確認します。「導入済み」と修正版の版が表示されることを確認してください。

アンインストール、設定削除、`tool.json`の手置きは不要です。正常終了を拒否した場合は、その処理を完了して再試行してください。強制終了はしません。

設定・保存画像・利用者が配置したFFmpeg等は保持します。撮影履歴は設定に従って起動中だけメモリーに保持され、正常終了で消えます。保存した画像ファイルは消えません。

復旧が未完了と表示された場合は、同じ登録先へ修正版setupを再実行します。予約が外部変更されているなど、自動復旧できない状態ではその情報を保持して中止します。
