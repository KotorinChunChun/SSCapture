# v0.20261010.1 要求定義

- [x] 撮影開始後、ドラッグしない左クリックでクリックしたディスプレイ全体を撮影する。
- [x] 中央クリックでクリック地点のウィンドウを撮影する。
- [x] 右クリックはキャンセルではなく、次の操作の出力先・設定・閉じる/キャンセルのメニューを表示する。
- [x] Escapeキーで選択をキャンセルする。
- [x] 右クリックメニューからクリップボード・ファイル・外部アプリの送信先を選べる。
- [x] 選んだ送信先だけに出力する（確認回答）。
- [x] Win+Shift+Rから録画を開始し、Win+Shift+Sからは録画を開始しない。
- [x] 録画の領域は静止画と同じ方法で選択する。
- [x] 録画は領域選択後に開始ボタンを押す方式とする（確認回答）。
- [x] PC再生音とマイク音声をそれぞれオン・オフできる（確認回答）。
- [x] 設定画面で録音に使用するマイクを選択できる。
- [x] 静止画と録画のショートカットはそれぞれ2枠を設定・変更できる。
- [x] PrintScreen単押しでも静止画撮影を起動する。
- [x] 撮影終了後に内容を渡す外部アプリを設定でき、本ツール自身には編集機能を持たせない。
- [x] 静止画は撮影キー受付時の画面を保持して選択し、選択中に進んだ未来の画面を撮らない。
- [x] 静止画の開始時画面固定を設定でオン・オフできる。
