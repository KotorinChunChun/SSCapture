# v0.1.0 正式導入の起動修正

## 2026年10月12日：同梱ランタイムの検索

- KotorinToysの正式導入検証中、SSCaptureの実Scheduler起動で「.NET Desktop Runtimeをインストールしてください」と表示された。
- `coreclr.dll`、`hostfxr.dll`、`hostpolicy.dll`と自己完結型のruntimeconfigは導入済みだったが、AppHostDotNetSearchが開発相対パスとGlobalだけを明示し、同梱先AppLocalを除外していた。
- 設計：SelfContained=trueではAppLocalだけを検索する。従来の開発用相対ランタイム探索はSelfContainedがtrueでない場合に維持する。設定・履歴・出力先・ランタイムの版は変更しない。
- 検証：win-x64の自己完結型発行成功。既存非対話テスト325件成功、失敗0。正式導入後の実起動結果は親のv0.1.0実装報告へ記録する。旧版資料の移動はしない。
- 実導入検証：ユーザーがエラー画面を閉じた後、専用正式導入先を更新した。実Schedulerの直接タスクから起動し、管理窓口の準備完了・direct_task経路・正常停止・予約保持を確認。起動エラーは再発しなかった。実サインイン・録画機能の受入とは区別する。
