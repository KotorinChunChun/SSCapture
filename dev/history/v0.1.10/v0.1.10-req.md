# SSCapture v0.1.10 候補の要求

- [x] 保存結果がない通知では「フォルダを開く」を表示せず、その位置のクリックを背後へ通す。
- [x] 未保存画像のサムネイルから従来どおりドラッグできる。
- [x] 通知の条件分岐と再表示をCLIで検証し、機能別試験をスクリプトから選べるようにする。

今回の範囲はローカル実装と検証。旧版からの要求の実装状況と実機確認の残件は[過去の指示と実装の照合](v0.1.10-imp.md#過去の指示と実装の照合)を参照。

- [x] 通知に部分失敗を明示し、再実行可能な失敗出力は通知から再実行できる。
- [x] ボタンの件数に合わせて配置と高さを調整し、編集ボタンの四隅を描画する。
- [x] サムネイルにドラッグの目印とホバー表示を加え、同じ寸法の繰り返しを省く。
- [x] 再撮影キーの案内を「直前の設定で再撮影するキー」に変更する。
- [x] 通常撮影ショートカットの直後に選択操作なしでEscを押した場合、前回の静止画出力結果を参考表示する。

- [x] 既存の撮影CLIで範囲と入出力プリセットを指定し、専用データからの単発撮影・保存先・結果を再現できるようにする。

## 撮影操作・通知の追加要求

- [x] 導入済みのPPPaintを静止画の外部アプリ候補に表示する。
- [x] 矩形ドラッグ中のSpaceで対角の起点へ切り替え、ポインタを元の始点へ移し、範囲を保持する。
- [x] ウィンドウを単押しで撮影した場合、通知にウィンドウ名を表示する。
- [x] 通知のサムネイルをダブルクリックして割り当て済みの編集アプリを起動する。
- [x] 撮影中のWin単押しでポインタ下の撮影対象を強調し、再度押すと解除する。
- [x] 修飾キーの単独・2キーの全10組とSpaceの動作を設定できるようにする。修飾キーの効果をポインタ近くに表示する。
- [x] 刻み幅の既定を1pxにする。

実キーと実アプリでの受け入れ確認は[実装報告](v0.1.10-imp.md#撮影操作通知の追加検証)を参照。

## ショートカットの段階分けと複数画面の選択

- [x] PC作業中、撮影範囲設定前、撮影ドラッグ中の3グループを設ける。撮影中の2グループは修飾キーを縦横に並べ、マウス操作も表示する。
- [x] ドラッグ開始前のWin単押しでウィンドウ撮影へ切り替え、再度押すと元のモードに戻る。ドラッグ中のWin単押しは無視する。
- [x] ウィンドウ撮影の右クリックメニューから、見えている画面の切り抜きとWGCによる対象ウィンドウ単独取得を選択できるようにする。
- [x] 複数モニタで選択範囲の更新が一方へ偏らないようにし、各モニタで変化した領域を描画する。

## 撮影確定前の案内とドラッグの既定操作

- [x] 左単押し・中押し・ドラッグ中のポインタに操作と取り消し方法を表示し、ボタンを離す前にEscまたは右クリックで取り消せるようにする。
- [x] 矩形ドラッグの既定をShiftで縦横比固定、Ctrlで中心基準、Ctrl＋Shiftで両方とする。従来の横・縦をAlt＋Shift・Alt＋Ctrlに、別モニター移動をWin長押しに割り当てる。
- [x] 既定のキー割り当てを設定ファイルで定義し、アプリの更新なしで編集できるようにする。
- [x] ドラッグ前のWin長押しでモニターを移動し、離した位置のモニターで撮影を続ける。静止したままの短押しはウィンドウ撮影へ切り替える。

- [x] Win短押しで入るウィンドウ撮影はWGCで対象だけを取得する。通常の囲うモードでの左単押しは、対象の枠内に見えている画面を撮影する。
- [x] 囲うモードで左ボタンを押してからドラッグが始まるまで、押した位置のウィンドウを明るく表示する。

## 撮影時のプレビューと操作用語

- [x] WGC単ウィンドウ撮影では、対象のWGC画像を他のウィンドウの手前にプレビューし、同じ画像で撮影を確定する。
- [x] 中ボタンを押している間は、撮影対象のモニター全体を明るく表示する。
- [x] 新規設定と本PCの撮影範囲設定前のAlt単押しをウィンドウ枠スナップに割り当てる。
- [x] ドラッグ中にグリッドを一時的に有効にするキーを設定できるようにし、画面と利用者向け文書の用語をグリッドとスナップに揃える。

## 複数対象の撮影と個別ガイド

- [x] 中ドラッグでWinなしにモニターをまたぎ、通過したモニターを合成する。
- [x] Winを押している間に、離してウィンドウ撮影へ切り替える操作を別行に表示する。
- [x] ウィンドウ撮影の左単押しは前面に見える子ウィンドウを含め、左ドラッグは軌跡を表示して対象を合成する。
- [x] 撮影前に開いていた設定画面を終了後に復元する。
- [x] 基本設定で画面右下とポインタ右下の操作ガイドを個別に切り替え、背景の暗転をOFFにした場合はドラッグ中も暗転しない。

## 基本設定の整理

- [x] 選択範囲、位置・寸法の補正、操作ガイド、既定プリセット、自動起動の順にまとめる。指定の項目名と説明を採用し、右クリックメニューと利用ガイドにも反映する。
- [x] 背景暗転OFF、両ガイドの個別切り替え、グリッドの一時使用、モニター制限ONでのキー移動を確認する。

## 撮影前後の状態と対象追従

- [ ] 撮影中に保存した設定が設定画面の古い値で上書きされないようにする。
- [ ] 撮影終了・キャンセル後に、もともと表示していた設定・履歴・ピン留めを復元する。
- [ ] 操作ガイドをタスクバーを除いた作業領域へ収める。
- [ ] WGCは付随ウィンドウの取得失敗で親全体を失わず、プレビュー失敗時は確定で再取得できるようにする。
- [ ] 直前に撮影したウィンドウをPIDなどから、デスクトップをモニター識別子から追跡する。
- [ ] 再撮影キーが未設定のときは通知にキー案内を表示しない。
