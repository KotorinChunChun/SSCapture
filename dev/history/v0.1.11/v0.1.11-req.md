# SSCapture v0.1.11 要求

各番号は[実装設計書](v0.1.11-imp.md)に対応する。表は現在の要求を示し、確認で決まった対象・条件は末尾に記録する。

## 実装済み

18項目を `feature/v0.1.11` に実装した。統合試験の結果と、外部アプリ・共有先を使う受け入れ試験の残件は[統合検証](v0.1.11-imp.md#14-統合検証)に記録する。

| 番号 | 利用者が求める動作 |
| --- | --- |
| 01 | 先に挙げたWinShotの良い機能をSSCaptureに取り入れる。 |
| 02 | ショートカットキーを日本語の利用者に分かりやすい文字で表示する。 |
| 03 | 利用者が選んだ単一ウィンドウの静止画を、出力時に内側へ切り抜く。上・下・左・右の切り抜き量をそれぞれpxで指定する。 |
| 04 | 外部の画像編集アプリとしてSnipping Toolを選べるようにする。 |
| 05 | 撮影位置を拡大鏡で確認でき、矢印キーでマウスポインタを1ドットずつ動かせるようにする。 |
| 06 | 始点と終点を2回のクリックで指定できる範囲選択方式をオプションにする。 |
| 07 | 範囲を囲う様子を画面共有・配信に載せるオプションを設ける。通常は背景の暗転を配信に載せない。 |
| 08 | 撮影中の右クリックメニューが閉じられず画面に残る不具合を修正する。 |
| 09 | 操作ヒントにCtrl、Shift、Windowsキーなど、追加したキー操作の説明を表示する。 |
| 10 | 定期キャプチャと時限キャプチャを利用できるようにする。 |
| 11 | 設定ファイルをインポート・エクスポートできるようにする。 |
| 12 | プリセットごとに撮影ショートカットを割り当て、用途に合う設定で撮影を開始できるようにする。 |
| 13 | ファイル保存を選ばない場合も、受け渡し用キャッシュの名前に命名規則を適用し、同名ファイルの衝突を回避する。 |
| 14 | 入力・出力プリセットの「既定にする」を「★既定にする」に変更する。 |
| 15 | マウスを指す設定項目「カーソル」を「マウスカーソル」に変更する。 |
| 16 | 撮影操作にキーを割り当て、押している間だけコントロールをフォーカスするモードへ切り替えられるようにする。離したら元の撮影操作に戻る。 |
| 17 | 通知領域の常駐アイコンと撮影中の右クリックメニューの機能を点検し、使う場面に合う不足コマンドを追加する。撮影結果の通知から行う操作も照合する。 |
| 18 | 基本設定の「自動起動」ラベルのすぐ横に「自動起動を適用」ボタンを置き、チェックを変更したときだけ濃い緑の背景と白文字で目立たせる。 |

「一時的に設定を変更したい」という追加要望は撤回された。その用途は要求12のプリセット別ショートカットで扱う。

## 確認で決まったこと

| 番号 | 決定内容 |
| --- | --- |
| 01 | v0.1.11でWinShotから採用する機能は、今回の要求で列挙したものに限る。 |
| 03 | 初出の「アクティブウィンドウ」は、撮影操作で利用者が選んだウィンドウを指す。設定場所は「出力プリセット → 出力・画像」。囲うモードの左単押しとWin短押し後のウィンドウ撮影に適用する。WGCで手前の所有ダイアログを含めた場合は合成した画像の外周を基準にする。 |
| 06・16 | 2点クリックは矩形の選択方式として任意に選ぶ。通常の囲うモードでは左単押しで枠内に見えている画面を撮る。部品選択キーを押している間にボタン内の文字やアイコンを指したら、ボタン全体を強調・撮影する。元アプリの入力フォーカスを保つ。 |
| 07 | 配信表示の既定はOFF。ONなら選択枠・軌跡とともに、実際に表示している暗転、画面右下とポインタ横の操作ガイド、拡大鏡、WGCのウィンドウプレビューも配信に載せる。WGCで他の窓に隠れていた映像も、手元のプレビューと同じ範囲を含める。対象はDiscord・Zoomのモニター全体共有と、OBSの画面キャプチャ。手元でOFFにした項目や一時的に隠れたガイドは配信でも消える。 |
| 10 | 定期撮影の初期出力はファイル保存のみ。命名規則に `{ocr}` があるときは自動認識で命名する。編集アプリなどを毎回使う場合は、その出力プリセットを明示的に選ぶ。予約時に選んだウィンドウは移動後も追跡する。 |
| 12 | 「ショートカットキー」「入力プリセット」「出力プリセット」を選んで複数行登録できる静止画専用の一覧を設ける。録画の開始は既存の録画キーを使う。1つの入力に用途別の出力を組み合わせられる。撮影中の右クリックでは引き続き片側だけ一時変更できる。 |
| 13 | 通知のドラッグ・外部編集で受け渡しファイルが必要になった時点で命名規則を適用する。クリップボードへのコピーはメモリ内で完了する。 |
| 18 | 「自動起動を適用」が確定するのは自動起動の変更のみ。新規設定はOFF、登録済みの自動起動では無表示で起動する。 |
