コードの未実装はなし。実操作の未確認範囲は[実装報告](v0.1.8-imp.md)に区別して記録する。

## 実装済

- [x] R01: 出力プリセットにピン留め表示を追加する。囲った範囲の座標へ静止画をフレームレス・常に最前面で表示し、複数枚を同時に設置できる。既存のコピー・保存・外部アプリ出力と併用する。
- [x] R02: 通常の左ドラッグで窓を移動。Ctrl＋ドラッグで作図、Ctrl＋Shift＋ドラッグで水平・垂直限定の線を描く。初期ペンは原色の赤・3px。右クリックで閉じる・ペンの設定を表示する。
- [x] R03: Shift＋ドラッグで窓内の範囲を選択。Ctrl＋Cで選択部分、未選択なら全体を描画込みでコピー。Ctrl＋Zで戻す、Ctrl＋Yでやり直す、Escで選択だけ解除、Ctrl＋Wで窓を閉じる。
- [x] R04: Ctrl＋Sで描画込みの画像を既定の出力フォルダ・命名パターンで保存する。保存ダイアログは出さない。ホイールで表示だけ拡大縮小、右クリックから倍率100％・元の撮影位置へ戻す。トレイで全ピン留めを一時非表示／再表示する。
- [x] R05: ZoomItを参考に、色切替、蛍光ペン、Ctrl＋ホイールで太さ変更、直線・矩形・楕円・矢印、Tで文字入力、Eで描画全消去を追加。全消去も取り消せる。文字や描画はコピー・保存に含む。
- [x] R06: Lで左90度、Rで右90度回転。画像と描画を一緒に回転する。Rは回転を優先し、赤ペンは右クリックメニューから選ぶ。操作はアクティブなピン留め窓だけに適用する。
- [x] R07: 設定画面に撮影コマンド生成を追加。範囲選択を開始する方式と固定範囲を即時撮影する方式の両方を用意し、入力・出力プリセットを指定したPowerShell用コマンドを生成・コピーできる。生成のみでは撮影しない。
- [x] R08: 生成コマンドを実際に受け付けて静止画を撮影する。既存設定・プリセット・通常起動と自動起動の挙動を維持し、撮影コマンドの実行で既定設定や起動予約を書き換えない。

## 質問と回答（QA）

| 論点 | 確定内容 |
| --- | --- |
| 静止画かライブか | 静止画限定。撮影後の元画面の変化には追従しない。 |
| 描画操作と初期ペン | 赤原色・3ドット。Ctrlで描画、Ctrl＋Shiftで水平垂直、Ctrl＋Zで戻す。通常の移動と分離する。 |
| 追加操作 | 提案したやり直し・選択解除・閉じる・保存・ズーム・元位置復帰・全窓一時非表示を採用。 |
| 保存先 | Ctrl＋Sは所定の出力フォルダ。既存の命名パターンを使い、保存ダイアログは不要。 |
| 色キーと回転の競合 | L/Rを回転へ優先。赤の選択は右クリックメニュー。その他の色キーとShiftによる蛍光ペンを維持する。 |
| コマンドの方式 | 範囲選択も固定範囲も使う。生成したPowerShellコマンドの実行時に撮影し、生成だけでは撮影しない。 |
| 実装開始 | 上記の会話を受け「それで実装して」と指示。新たな公開指示はない。 |
| このPCへの導入 | 2026-10-29、正式導入先を入れ替えて動作確認する。既存の設定・前回範囲・起動予約を保持する。 |

既定の実装判断: ピン留めはプロセス起動中だけ保持し終了時に破棄。ペン幅は画像の物理px単位でズーム倍率と独立。Ctrl＋Sは全体画像、Ctrl＋Cのみ選択範囲を優先する。回転時は選択を解除する。既存画像を壊さないコピーへ描画する。
