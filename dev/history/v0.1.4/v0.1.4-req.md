- [x] R04: File出力で保存・命名・OCR・フォルダー操作の有効性と検証を切り替える。
- [x] R05: 外部アプリを用途ごとに複数登録し1つ選択、設定移行と参照保護。
- [x] R06: 出力プリセットへ改称。
- [x] R07: 撮影時のUIA・ポインタ・アプリ情報をPNG内XMP／JSON／両方で記録。既定はなし。
- [x] R08: 履歴を独立設定区分・既存の別画面へ分離。
- [x] R09: 入力プリセットへ改称。

## 確認済み仕様・QA

2026-10-22追加: 提案した3分類と設定・キャンセルの配置を承認。画面固定／カーソルは切替時に画面を再取得して今回の撮影へ適用する。通知・ショートカット等の常駐設定は設定画面に残す。v0.1.4を維持し、まだ公開しない。

| 論点 | 回答・適用 |
| --- | --- |
| 版と公開 | v0.1.4として全項目を実装。公開しない |
| 暗転 | 初期設定OFF・設定でONにできる。画面固定とは別 |
| 外部アプリ | 複数登録から1つ選ぶ。画像用・動画用に登録 |
| 記録形式 | PNG内XMP／別JSON／両方を選択できる。なしが既定 |
| 記録対象 | 静止画のファイル保存。カーソル描画の有無と位置記録は独立。フォーカスUIとポインタ下UIを区別 |
| 履歴 | 入力・出力プリセットと別画面・別設定区分。KeepHistoryに従い起動中のみ20件・256MiB上限で保持 |
| 固定範囲 | 登録した位置・幅・高さをキーで選択画面なしに再撮影。既存実装を維持して名称・一覧を明確化 |
| 既存機能 | 8/4ビットのPNG・DIBコピー、白余白、出力再実行、Space基点・方向ロック等を維持 |
| 追加実装の版 | v0.1.4へ追加実装。まだ公開しない |
| モニタ解除 | Ctrl＋Shiftを押しながら別モニタへ移動。その撮影の残りは全デスクトップが対象、次回は元の制限 |
| 撮影中の入力プリセット | 即撮影ではなく、枠を切り替えて調整・確定する方式 |
| 通知クリックのアプリ | 登録した多数のアプリから通知専用の1つを選択 |
| 案内の回避 | 現状の隠れる動作が効かないように見えるため、逃げる動作を希望 |

| 外部アプリ新規 | 選択時は入力だけ。「保存」で一覧登録。設定画面の「保存」で確定する現在の二段階を維持 |
| 未保存画像 | 開く操作時だけ生成し、書込完了後に起動。起動後1分保持可。{file}を維持 |
