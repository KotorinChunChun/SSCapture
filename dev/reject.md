# 対応しない事項

ユーザーが明示した不要機能・採用しない動作を記録する。新機能の調査・提案でも該当するものを候補に戻さない。後の明示要求で変更された事項は、その適用範囲を区別する（2026-10-10整理）。

## 現在の除外事項

- 遅延撮影・定間隔撮影・画像の画面へのピン留め・スクロール撮影は不要（v0.20261010.7、前回提案の「遅延撮影から後」は不要との指定）。

- 本ツール自身の画像編集機能は不要。標準Snipping Toolの画像編集機能を内蔵せず、編集は外部アプリへ渡す（v0.20261010.0 / .1）。
- 撮影ごとに保存先フォルダ・任意ファイル名を選ぶ保存ダイアログは不要。設定したフォルダと命名パターンを使う（v0.20261010.0）。
- 静止画のWin＋Shift＋Sから録画は開始しない。録画は別のショートカットから開始する（v0.20261010.1）。
- 選択画面の右クリックを即キャンセルにはしない。右クリックはメニュー、Escapeはキャンセルにする（v0.20261010.1）。
- ショートカット各枠に別の有効/無効設定を設けない。キーの「なし」で判断する。トレイの一時停止機能とは区別する（v0.20261010.2）。
- 設定・OCR画面の最小化/最大化ボタンは不要。タイトルバーは閉じるボタンだけとする（v0.20261010.6）。
- 即時撮影では、通常設定がONでも外部アプリ起動・保存後のフォルダ表示を実行しない（v0.20261010.6 確認回答）。通常撮影では引き続き設定可能。

## 後の要求で採用・例外となった事項

- 即時撮影の画面への影響は最小限とするが、v0.20261010.8で通常/即時両方の完了オーバーレイと短い効果音を明示採用。外部アプリ起動・保存後フォルダ表示の除外は維持する。

- 初版v0.20261010.0では録画・OCRを含めないとしたが、追加要求により録画はv0.20261010.1、OCRによるファイル命名はv0.20261010.3で採用済み。現在の一律な除外事項としては扱わない。
- 撮影ごとの任意ファイル名入力は不要だが、OCR行選択・採用文字列の編集はv0.20261010.3で採用。OCR画面の命名パターン・年月日・時分秒・保存後のフォルダ表示の変更もv0.20261010.5で採用しており、これらは保存ダイアログ不要の例外として維持する。
