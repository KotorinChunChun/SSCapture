# KotorinToys管理処理の固定ソース

本フォルダーのC#ソースは同じ作者のKotorinToysから、`source.json`に記録したコミットとGit blobで固定して収録したものです。元の名前空間と処理を維持し、独立したSSCaptureのビルドが隣接リポジトリの作業内容へ依存しないようにしています。

元リポジトリ: https://github.com/KotorinChunChun/KotorinToys

SSCapture専用の入口、旧0.1.2の検証、操作記録は一つ上のフォルダーに置きます。このフォルダーを変更する場合は、採用元の変更とSSCapture独自変更を区別し、再検証してください。

元コミットにLICENSEファイルは確認できていないため、独自のOSSライセンスを付与していません。第三者への公開条件の変更は本修正に含めません。
